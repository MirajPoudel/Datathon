# Machine Learning & Data Science Internship

This repository contains my work and practical implementations as part of the **Machine Learning & Data Science Internship at Datathon**.

Throughout this internship, I am exploring and applying various concepts of Data Science and Machine Learning, including data preprocessing, exploratory data analysis, feature engineering, model development, and evaluation.

This repository serves as a collection of my learning journey, assignments, experiments, and practical projects completed during the internship.

## 🛠️ Technologies & Tools

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Jupyter Notebook
- Git & GitHub

## 🚀 Projects

### 1. Multi-Class Benchmark Classification Pipeline (Iris / Wine)
**Task 1**

Built end-to-end multi-class classification pipelines using Scikit-learn, including data preprocessing, normalization, model training, and confusion matrix evaluation.

### 2. Real Estate Housing Price Prediction (Ridge & Lasso Regression)
**Task 2**

Developed regression models to predict housing prices using feature engineering, regularization techniques, and residual error analysis.

### 3. Predictive Customer Churn Classifier (Random Forest & XGBoost)
**Task 3**

Built customer churn prediction models, addressed severe class imbalance, and focused on optimizing ROC-AUC performance.

### 4. NLP Sentiment Classification on Customer Reviews (TF-IDF)
**Task 4**

Developed a sentiment classification pipeline by preprocessing text data, extracting TF-IDF features, and classifying customer reviews based on sentiment polarity.
